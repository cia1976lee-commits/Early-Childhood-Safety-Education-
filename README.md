# 유아 안전교육 (Early Childhood Safety Education)

유아(만 3~5세)가 일상생활에서 위험을 알아차리고 스스로를 지킬 수 있도록 돕는 안전교육 자료를 모아 만드는 프로젝트입니다.

## 목표

- 유아 눈높이에 맞춘 쉬운 말과 그림으로 안전 습관을 익히게 합니다.
- 교사와 보호자가 교실과 가정에서 바로 쓸 수 있는 자료를 제공합니다.
- 놀이와 활동 중심으로 반복해 익힐 수 있게 구성합니다.

## 교육 영역

| 영역 | 주요 내용 |
| --- | --- |
| 교통안전 | 횡단보도 건너기, 신호등 지키기, 차 안에서 안전띠 매기 |
| 화재안전 | 불이 났을 때 대피하기, 119 신고하기, 불장난하지 않기 |
| 생활안전 | 뜨거운 것·날카로운 것 조심하기, 놀이기구 바르게 타기 |
| 신변안전 | 낯선 사람 따라가지 않기, 내 몸 소중히 여기기, 길 잃었을 때 대처하기 |
| 물놀이안전 | 어른과 함께 물놀이하기, 구명조끼 입기 |
| 재난안전 | 지진·태풍 등 재난 상황에서 몸 보호하기 |
| 약물·식품안전 | 약은 어른이 줄 때만 먹기, 모르는 음식 함부로 먹지 않기 |

## 구성 예정

- 영역별 교육 자료 (활동 안내, 그림 자료)
- 유아용 상호작용 활동 (퀴즈, "이럴 땐 어떻게 할까요?" 상황 선택)
- 교사용 활동 계획안
- 보호자용 가정 연계 안내문 및 안전 점검표

## 모의수업 계획안 피드백 앱

[`lesson-plan-feedback/index.html`](lesson-plan-feedback/index.html)은 「교과교재연구 및 지도법 모의수업 수업역량 강화 운영 기획안」의 **3-2. 계획안 피드백 기준**으로 예비유아교사의 계획안을 점검하는 단일 HTML 앱입니다. 설치나 빌드 없이 브라우저에서 파일을 열면 됩니다.

- **6개 기준 자동 점검**: 놀이 출발점, 교재교구, 유연성, 상호작용 계획, 통합성, 관찰·기록을 기준마다 4~5개 항목으로 확인하고 충족·보완·미흡으로 표시합니다. 교수자 평가표 배점 영역도 함께 보여 줍니다.
- **질문으로 안내**: 기획안의 운영 원칙에 따라 고친 문장을 대신 써 주지 않고, 학생이 스스로 답해 볼 보완 질문을 제시합니다.
- **발문 분석**: 물음표로 끝나는 예상 발문을 찾아 개방형·폐쇄형·제안형으로 나누고 비율을 보여 줍니다.
- **누리과정 5개 영역 확인**: 영역 칸에 적은 영역이 실제 놀이 흐름에서도 드러나는지 비교합니다.
- **개인정보 확인**: 유아 실명으로 보이는 표현, 전화번호, 사진 첨부 언급을 찾아 알려 줍니다.
- **입력 방식**: 항목별 작성, 또는 전체 붙여넣기·`.docx`/`.txt` 파일 불러오기. 작성 중인 내용은 브라우저에 임시 저장됩니다.
- **Claude 심화 피드백**: claude.ai에 게시된 페이지에서 열면 계획안 문장을 근거로 한 기준별 진단과 질문을 받을 수 있습니다(참고 의견, 최종 평가는 교수자).
- **피드백 전체 복사**: 점검 결과를 텍스트로 복사해 성찰 메모나 제출 자료에 붙일 수 있습니다.

자동 점검은 키워드와 문장 형태를 바탕으로 한 1차 점검이므로, 판정 자체보다 보완 질문을 실마리로 활용하세요.

## 참고

교육 영역은 교육부 「학교안전교육 7대 표준안」의 7대 영역(생활안전, 교통안전, 폭력예방 및 신변보호, 약물 및 사이버 중독 예방, 재난안전, 직업안전, 응급처치)을 바탕으로 유아 수준에 맞게 조정할 예정입니다.
