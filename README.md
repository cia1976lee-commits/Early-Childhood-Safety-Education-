# 유아 안전교육 (Early Childhood Safety Education)

유아(만 3~5세)가 일상생활에서 위험을 알아차리고 스스로를 지킬 수 있도록 돕는 안전교육 자료를 모아 만드는 프로젝트입니다.

## 목표

- 유아 눈높이에 맞춘 쉬운 말과 그림으로 안전 습관을 익히게 합니다.
- 교사와 보호자가 교실과 가정에서 바로 쓸 수 있는 자료를 제공합니다.
- 놀이와 활동 중심으로 반복해 익힐 수 있게 구성합니다.

## 교육 영역

| 영역 | 주요 내용 |
| --- | --- |
| 교통안전 | 횡단보도 건너기, 신호등 지키기, 차 안에서 안전띠 매기 |
| 화재안전 | 불이 났을 때 대피하기, 119 신고하기, 불장난하지 않기 |
| 생활안전 | 뜨거운 것·날카로운 것 조심하기, 놀이기구 바르게 타기 |
| 신변안전 | 낯선 사람 따라가지 않기, 내 몸 소중히 여기기, 길 잃었을 때 대처하기 |
| 물놀이안전 | 어른과 함께 물놀이하기, 구명조끼 입기 |
| 재난안전 | 지진·태풍 등 재난 상황에서 몸 보호하기 |
| 약물·식품안전 | 약은 어른이 줄 때만 먹기, 모르는 음식 함부로 먹지 않기 |

## 구성 예정

- 영역별 교육 자료 (활동 안내, 그림 자료)
- 유아용 상호작용 활동 (퀴즈, "이럴 땐 어떻게 할까요?" 상황 선택)
- 교사용 활동 계획안
- 보호자용 가정 연계 안내문 및 안전 점검표

## 라온 · 모의수업 계획안 피드백 앱

[`lesson-plan-feedback/index.html`](lesson-plan-feedback/index.html)(라온, ‘즐거운’을 뜻하는 옛말)은 계획안 파일을 올리면 「교과교재연구 및 지도법 모의수업 수업역량 강화 운영 기획안」의 **3-2. 계획안 피드백 기준**으로 분석해 검토 보고서를 만들어 주는 단일 HTML 앱입니다. 설치나 빌드 없이 브라우저에서 열면 됩니다.

**PC용 가로형 화면**: 왼쪽에 파일 올리기와 읽은 파일 정보가 고정되고, 오른쪽 넓은 영역에서 ‘검토 보고서 · 읽은 내용 확인·수정 · 원문’ 탭을 오갑니다. 기준 카드는 넓은 화면에서 3열로 펼쳐집니다.

**흐름: 파일 올리기 → 분석 → 보고서 내려받기**

1. **파일 올리기**: `.hwp`(한글 5.0 이상), `.hwpx`, `.docx`, `.pdf`, `.txt`를 끌어다 놓거나 선택합니다. 파일은 브라우저 안에서만 읽습니다(PDF는 처음 한 번 pdf.js를 cdnjs에서 불러옵니다).
2. **분석**: ‘놀이 출발점’, ‘교재교구’, ‘예상 발문’ 같은 항목 제목을 찾아 내용을 나눈 뒤 6개 기준으로 점검합니다. 표로 된 계획안(제목 칸 | 내용 칸)도 인식하며, 제목을 못 찾은 기준은 문서 전체에서 확인합니다. 인식 결과는 화면에서 고칠 수 있고, 고치면 보고서가 바로 바뀝니다.
3. **검토 보고서**: 기준별 판정(충족·보완·미흡)과 확인 항목, 교수자 평가표 배점 영역, 스스로 답해 볼 보완 질문, 예상 발문 분류(개방형·폐쇄형·제안형), 누리과정 5개 영역 확인, 개인정보 경고를 보여 줍니다. **Word(.docx) 보고서로 내려받거나** 텍스트로 복사할 수 있습니다.

- **질문으로 안내**: 기획안의 운영 원칙에 따라 고친 문장을 대신 써 주지 않고 질문으로 안내합니다.
- **Claude 심화 피드백**: claude.ai에 게시된 페이지에서 열면 파일을 올릴 때 계획안 문장을 근거로 한 기준별 진단과 질문도 받아 보고서에 함께 넣습니다(참고 의견, 최종 평가는 교수자). 개인정보로 보이는 표현이 있으면 보내지 않습니다.
- **예시 계획안**: [`samples/`](lesson-plan-feedback/samples)에 교사주도형 계획안(도입·전개·마무리 표 양식)과 놀이중심 계획안 예시가 있어, 올려 보며 결과를 비교할 수 있습니다.
- **항목 인식**: 활동 목표·활동 유형·소요 시간 같은 칸은 기준과 관계없는 항목으로 보고 건너뜁니다. 항목 제목을 3개 이상 찾은 계획안은 없는 항목을 ‘내용 없음’으로 판정하고, 예상 발문 칸이 없으면 활동 흐름(도입·전개·마무리)에서 발문을 찾습니다.
- **학과 서식 대응**: 교과교재연구및지도법 ‘모의수업 시연계획안’ 서식(활 동 명·대상연령·활동유형·활동목표·누리과정 관련요소·활동자료·활동방법(도입·전개·마무리)·유의사항)을 읽습니다. 글자 사이를 띄운 제목도 알아보고, 발문은 활동방법의 `T:`(교사) 대사에서만 찾으며 `C:`(유아) 대사는 빼고, 대안 칸이 없으면 활동방법·유의사항의 조건부 대응(‘역할 분쟁 시’, ‘흥미가 유지될 때만’ 등)을 찾습니다.
- **교수자 피드백 형식**: 보고서 첫머리에 모의수업 평가결과처럼 ‘잘한 점 / 개선할 점’ 한 줄 평을 두고, 기준마다 잘된 점을 먼저 보여 준 뒤 생각해 볼 질문을 제시합니다.
- **읽을 수 없는 파일**: 암호가 걸렸거나 배포용으로 저장한 HWP, 예전 Word(.doc), 스캔한 PDF는 안내 메시지를 띄웁니다.

자동 점검은 키워드와 문장 형태를 바탕으로 한 1차 점검이므로, 판정 자체보다 보완 질문을 실마리로 활용하세요.

### 웹사이트로 배포 (GitHub Pages)

`main` 브랜치에 `lesson-plan-feedback/` 변경이 올라가면 [`.github/workflows/pages.yml`](.github/workflows/pages.yml)이 [`scripts/build-pages.sh`](scripts/build-pages.sh)로 앱을 완전한 웹페이지(`_site/index.html`)로 만들어 GitHub Pages에 배포합니다. Actions 탭에서 직접 실행할 수도 있습니다.

처음 한 번은 저장소 설정이 필요합니다.

1. 저장소를 공개(public)로 바꾸거나 GitHub Pro 이상 플랜을 사용합니다. 무료 계정의 비공개 저장소는 Pages를 쓸 수 없습니다.
2. **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 바꿉니다.

배포 주소: `https://cia1976lee-commits.github.io/Early-Childhood-Safety-Education-/`

웹사이트 버전에서는 파일 분석, 자동 점검 보고서, Word 보고서 내려받기가 모두 됩니다. Claude 심화 피드백은 claude.ai에서 열었을 때만 작동합니다.

## 참고

교육 영역은 교육부 「학교안전교육 7대 표준안」의 7대 영역(생활안전, 교통안전, 폭력예방 및 신변보호, 약물 및 사이버 중독 예방, 재난안전, 직업안전, 응급처치)을 바탕으로 유아 수준에 맞게 조정할 예정입니다.
