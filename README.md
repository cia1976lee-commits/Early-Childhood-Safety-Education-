# 유아 안전교육 (Early Childhood Safety Education)

유아(만 3~5세)가 일상생활에서 위험을 알아차리고 스스로를 지킬 수 있도록 돕는 안전교육 자료를 모아 만드는 프로젝트입니다.

## 목표

- 유아 눈높이에 맞춘 쉬운 말과 그림으로 안전 습관을 익히게 합니다.
- 교사와 보호자가 교실과 가정에서 바로 쓸 수 있는 자료를 제공합니다.
- 놀이와 활동 중심으로 반복해 익힐 수 있게 구성합니다.

## 교육 영역

| 영역 | 주요 내용 |
| --- | --- |
| 교통안전 | 횡단보도 건너기, 신호등 지키기, 차 안에서 안전띠 매기 |
| 화재안전 | 불이 났을 때 대피하기, 119 신고하기, 불장난하지 않기 |
| 생활안전 | 뜨거운 것·날카로운 것 조심하기, 놀이기구 바르게 타기 |
| 신변안전 | 낯선 사람 따라가지 않기, 내 몸 소중히 여기기, 길 잃었을 때 대처하기 |
| 물놀이안전 | 어른과 함께 물놀이하기, 구명조끼 입기 |
| 재난안전 | 지진·태풍 등 재난 상황에서 몸 보호하기 |
| 약물·식품안전 | 약은 어른이 줄 때만 먹기, 모르는 음식 함부로 먹지 않기 |

## 구성 예정

- 영역별 교육 자료 (활동 안내, 그림 자료)
- 유아용 상호작용 활동 (퀴즈, "이럴 땐 어떻게 할까요?" 상황 선택)
- 교사용 활동 계획안
- 보호자용 가정 연계 안내문 및 안전 점검표

## 쫑알톡톡 · 모의수업 계획안 피드백 친구

> “쫑알쫑알 나누면, 수업 아이디어가 톡톡!”

[`lesson-plan-feedback/index.html`](lesson-plan-feedback/index.html)(쫑알톡톡)은 모의수업 활동계획안 파일을 올리면 「유아교육과 모의수업 활동계획안 평가 루브릭(안)」으로 채점 초안을 만들고, **학생용 피드백지**와 **교수자용 채점표**를 만들어 주는 단일 HTML 앱입니다. 채점 기준은 `mock-lesson-plan-scoring` 스킬과 같습니다. 설치나 빌드 없이 브라우저에서 열면 됩니다(PC용 가로형 화면).

**흐름: 파일 올리기 → 채점 초안 → 피드백지·채점표 내려받기**

1. **파일 올리기**: `.hwp`(한글 5.0 이상), `.hwpx`, `.docx`, `.pdf`, `.txt`. 파일은 브라우저 안에서만 읽습니다(PDF는 처음 한 번 pdf.js를 cdnjs에서 불러옵니다).
2. **칸 나누기**: 학과 ‘모의수업 시연계획안’ 서식(활 동 명·대상연령·활동유형·활동목표·누리과정 관련요소·활동자료·활동방법(도입·전개·마무리)·유의사항)을 읽고, 활동방법의 `T:`(교사)·`C:`(예상 유아 반응) 대화에서 교사 발문을 찾습니다. 잘못 나뉘면 ‘읽은 내용 확인·수정’ 탭에서 고칠 수 있습니다.
3. **채점 초안**: 7개 영역 20개 항목(활동 목표 15 · 누리과정 연계 10 · 활동 내용 20 · 활동 전개 20 · 발문·상호작용 20 · 자료·환경 10 · 평가·확장 5)을 항목별 1~5점으로 채점합니다.
   - **관대 채점**: 요소가 일부라도 드러나면 3점부터 보고, 1점은 미제시일 때만 줍니다.
   - **오류 유형과 상한**: 정답 확인형 발문 위주(A4-1), 관찰·기록 계획 없음(A6-1), 공간·동선 계획 누락(A2-5) 등 오류 유형이 보이면 해당 항목 점수에 상한을 적용합니다.
   - **원문 근거**: 모든 점수에 계획안 원문 근거를 붙이고, 영역 소계와 총점은 코드로 계산해 서로 맞는지 확인합니다.
4. **학생용 피드백지**: 영역별 수준(● 잘 드러남 / ◐ 조금 더 다듬기 / ○ 보완이 필요함) → 강점 2~3개 → 보완점 최대 4개(부족한 부분 + 해결방안) → 종합의견과 ‘가장 먼저 고칠 것’ 순서입니다. 점수는 교수자가 확정한 뒤 채점표 탭에서 켤 때만 표시됩니다.
5. **교수자용 채점표**: 20개 항목 점수·근거·오류 코드·비고, 영역 소계와 총점, 발문 분류, 교수 확인 필요 항목, 교수자 종합의견 초안을 보여 줍니다.
6. **내려받기**: 학생용 피드백지(A4 세로)와 교수자용 채점표(A4 가로)를 각각 Word(.docx)로 내려받습니다. 파일 이름에는 학생 이름 대신 활동명을 씁니다.

- **두 가지 채점 방식**: 어디서나 키워드 기반 **자동 채점 초안**이 나옵니다. claude.ai에서 열면 **Claude 정밀 채점**으로 같은 루브릭·오류 유형·문체 규칙에 따라 계획안을 읽고 다시 채점합니다. 상한과 합계는 앱이 다시 확인합니다.
- **개인정보**: 유아 실명으로 보이는 표현이 있으면 경고하고, 그 경우 Claude로 보내지 않습니다.
- **예시 계획안**: [`samples/`](lesson-plan-feedback/samples)에 교사주도형·놀이중심 예시가 있습니다.
- **읽을 수 없는 파일**: 암호가 걸린 HWP, 배포용 HWP, 예전 Word(.doc), 스캔한 PDF는 안내 메시지를 띄웁니다.
- 모든 결과는 **채점 초안 — 교수 확정 전**이며, 최종 점수는 교수자가 확정합니다.

### 웹사이트로 배포 (GitHub Pages)

`main` 브랜치에 `lesson-plan-feedback/` 변경이 올라가면 [`.github/workflows/pages.yml`](.github/workflows/pages.yml)이 [`scripts/build-pages.sh`](scripts/build-pages.sh)로 앱을 완전한 웹페이지(`_site/index.html`)로 만들어 GitHub Pages에 배포합니다. Actions 탭에서 직접 실행할 수도 있습니다.

처음 한 번은 저장소 설정이 필요합니다.

1. 저장소를 공개(public)로 바꾸거나 GitHub Pro 이상 플랜을 사용합니다. 무료 계정의 비공개 저장소는 Pages를 쓸 수 없습니다.
2. **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 바꿉니다.

배포 주소: `https://cia1976lee-commits.github.io/Early-Childhood-Safety-Education-/`

웹사이트 버전에서는 파일 분석, 자동 점검 보고서, Word 보고서 내려받기가 모두 됩니다. Claude 심화 피드백은 claude.ai에서 열었을 때만 작동합니다.

## 참고

교육 영역은 교육부 「학교안전교육 7대 표준안」의 7대 영역(생활안전, 교통안전, 폭력예방 및 신변보호, 약물 및 사이버 중독 예방, 재난안전, 직업안전, 응급처치)을 바탕으로 유아 수준에 맞게 조정할 예정입니다.
