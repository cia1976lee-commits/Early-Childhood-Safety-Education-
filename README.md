# 유아 안전교육 (Early Childhood Safety Education)

유아(만 3~5세)가 일상생활에서 위험을 알아차리고 스스로를 지킬 수 있도록 돕는 안전교육 자료를 모아 만드는 프로젝트입니다.

## 목표

- 유아 눈높이에 맞춘 쉬운 말과 그림으로 안전 습관을 익히게 합니다.
- 교사와 보호자가 교실과 가정에서 바로 쓸 수 있는 자료를 제공합니다.
- 놀이와 활동 중심으로 반복해 익힐 수 있게 구성합니다.

## 교육 영역

| 영역 | 주요 내용 |
| --- | --- |
| 교통안전 | 횡단보도 건너기, 신호등 지키기, 차 안에서 안전띠 매기 |
| 화재안전 | 불이 났을 때 대피하기, 119 신고하기, 불장난하지 않기 |
| 생활안전 | 뜨거운 것·날카로운 것 조심하기, 놀이기구 바르게 타기 |
| 신변안전 | 낯선 사람 따라가지 않기, 내 몸 소중히 여기기, 길 잃었을 때 대처하기 |
| 물놀이안전 | 어른과 함께 물놀이하기, 구명조끼 입기 |
| 재난안전 | 지진·태풍 등 재난 상황에서 몸 보호하기 |
| 약물·식품안전 | 약은 어른이 줄 때만 먹기, 모르는 음식 함부로 먹지 않기 |

## 구성 예정

- 영역별 교육 자료 (활동 안내, 그림 자료)
- 유아용 상호작용 활동 (퀴즈, "이럴 땐 어떻게 할까요?" 상황 선택)
- 교사용 활동 계획안
- 보호자용 가정 연계 안내문 및 안전 점검표

## 참고

교육 영역은 교육부 「학교안전교육 7대 표준안」의 7대 영역(생활안전, 교통안전, 폭력예방 및 신변보호, 약물 및 사이버 중독 예방, 재난안전, 직업안전, 응급처치)을 바탕으로 유아 수준에 맞게 조정할 예정입니다.
